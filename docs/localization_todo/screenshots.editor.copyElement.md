# screenshots.editor.copyElement

- **English value**: `Copy element`
- **Namespace**: `screenshots`
- **File/component**: `src/modules/screenshots/ScreenshotEditor.tsx`
- **UI role**: `label`
- **User flow**: Shown in the native context menu when the user right-clicks a selected screenshot-editor annotation. Activating it creates a slightly offset clone and selects the clone.
- **Tone**: `concise/neutral`
- **Placeholders**: `none`
- **Context/meaning**: `Copy element` means duplicate the selected canvas element in place; it does not copy text or image data to the system clipboard.
- **Domain notes**: Screenshot-editor elements include shapes, freehand strokes, mosaic regions, and text annotations.
