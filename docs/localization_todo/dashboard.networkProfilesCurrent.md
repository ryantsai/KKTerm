# dashboard.networkProfilesCurrent

- **English value**: `Current`
- **Namespace**: `dashboard`
- **File/component**: `src/modules/dashboard/widgets/builtin/network-profiles/NetworkProfilesWidget.tsx`
- **UI role**: status chip
- **User flow**: Shown on a profile card instead of the Apply button when the profile already matches the selected adapter’s live configuration.
- **Tone**: short status word
- **Placeholders**: none
- **Context/meaning**: Means the adapter is already using this configuration; it is not “current” as in up to date or latest.
- **Domain notes**: “Profile” means a saved IPv4/IPv6 network configuration, not a KKTerm Connection. Preserve IPv4, IPv6, DNS, and UAC as technical terms.
