# settings.fullBackupImportHint

- **English value**: `Imports the KKTerm settings database and reloads the app.`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/SelectiveImportDialog.tsx`
- **UI role**: `hint`
- **User flow**: Shown after the user chooses a full database-backup ZIP for import.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: Describes replacement of the ordinary KKTerm settings database without implying that Custom Modules are imported.
- **Domain notes**: Custom Modules are top-level optional Modules. Their metadata and data are explicitly excluded and remain unchanged on import.
