# itops.ipam.unassignedAddresses

- **English value**: `Unassigned addresses`
- **Namespace**: `itops`
- **File/component**: `src/modules/itops/IpamPanel.tsx`
- **UI role**: `heading`
- **User flow**: Labels Address Records that exist in IPAM but are not contained by any Prefix in the same VRF.
- **Tone**: `concise/technical`
- **Placeholders**: `none`
- **Context/meaning**: `Unassigned` means not organized under a containing IP Prefix; it does not mean unused, unleased, or unreachable.
- **Domain notes**: Address Records remain durable and editable in this group.
