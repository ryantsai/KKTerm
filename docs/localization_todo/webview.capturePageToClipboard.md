# webview.capturePageToClipboard

- **English value**: `Capture Page`
- **Namespace**: `webview`
- **File/component**: `src/modules/workspace/connections/webview/WebViewWorkspace.tsx`
- **UI role**: `button`
- **User flow**: The user opens the URL Connection screenshot menu and captures the complete scrollable page.
- **Tone**: `concise/neutral`
- **Placeholders**: `none`
- **Context/meaning**: Capture and stitch the full web page. Delivery follows Settings → Screenshots rather than always using the clipboard.
- **Domain notes**: URL Connection is the durable embedded browser resource; Capture Mode may save to the Screenshots library, copy to the clipboard, or do both.
