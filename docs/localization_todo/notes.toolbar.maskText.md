# notes.toolbar.maskText

- **English value**: `Mask selected text`
- **Namespace**: `notes`
- **File/component**: `src/modules/notes/NoteToolbar.tsx`
- **UI role**: `label`
- **User flow**: The label identifies the toolbar action that visually masks the selected text in a Connection Note. Selecting the same masked range and using the action again removes the mask.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: Hide selected note text behind an animated visual mask; this is not encryption or a password-store action.
- **Domain notes**: Connection Notes retain masked text as ordinary note content. The mask resets to hidden when the note window is reopened.
