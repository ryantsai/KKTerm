# settings.hideSensitiveHeaderValues

- **English value**: `Hide sensitive values`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/AiSettings.tsx`
- **UI role**: `label`
- **User flow**: Users toggle whether recognizable authorization, token, secret, password, and API-key custom-header values are masked in the AI provider header editor.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: Hide means visually mask sensitive custom HTTP header values in this editor only. It does not remove, encrypt, or stop sending those values.
- **Domain notes**: HTTP, API, bearer tokens, and header names typically stay English where appropriate.
