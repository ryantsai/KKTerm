# webview.openDownloadFolder

- **English value**: `Open download folder`
- **Namespace**: `webview`
- **File/component**: `src/modules/workspace/connections/webview/WebViewWorkspace.tsx`
- **UI role**: `button`
- **User flow**: The final native-menu command opens the effective URL download directory in the OS file manager.
- **Tone**: concise/direct
- **Placeholders**: none
- **Context/meaning**: Open the containing download directory, not an individual downloaded file.
- **Domain notes**: On Windows this opens File Explorer; other platforms use their default file manager.
