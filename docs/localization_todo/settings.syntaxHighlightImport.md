# settings.syntaxHighlightImport

- **English value**: `Import`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/SyntaxHighlightProfiles.tsx`
- **UI role**: `button`
- **User flow**: The user sees this compact action beside the profile name while adding or editing a keyword-highlighting profile. It opens a picker for a SecureCRT keyword INI file.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: “Import” means bring a profile into KKTerm from a file, not upload it to a remote service.
- **Domain notes**: SecureCRT and INI are intentionally omitted from the visible button because the file picker title and filter provide that technical context.
