# notes.toolbar.textColor

- **English value**: `Text color`
- **Namespace**: `notes`
- **File/component**: `src/modules/notes/NoteToolbar.tsx`
- **UI role**: `label`
- **User flow**: The label identifies the toolbar color control while a user formats selected note text. The same control opens the color picker and lets the user clear the selected text's custom color.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: The color applied to selected note text, not the note background, highlight color, or application theme color.
- **Domain notes**: Connection Notes are rich-text notes bound to a Connection. The picker stores safe hex text colors in the note's HTML.
