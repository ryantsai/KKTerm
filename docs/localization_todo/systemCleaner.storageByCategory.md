# systemCleaner.storageByCategory

- **Namespace**: `systemCleaner`
- **File/component**: `src/modules/system-cleaner/SystemCleanerPage.tsx`
- **UI role**: `heading`
- **User flow**: Label of the donut-chart card on the System Cleaner Overview summary, showing how the scanned drive splits across file categories.
