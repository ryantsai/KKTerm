# dashboard.notesDeleteTableRow

- **English value**: `Delete row`
- **Namespace**: `dashboard`
- **File/component**: `src/modules/dashboard/widgets/builtin/notes/NotesWidget.tsx`
- **UI role**: `button`
- **User flow**: Shown while the caret is inside a Notes table body cell. Deletes the active row.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: Row means a horizontal table row; the required Markdown header row cannot be deleted with this action.
- **Domain notes**: In zh-TW table terminology, row is `列` and column is `欄`.
