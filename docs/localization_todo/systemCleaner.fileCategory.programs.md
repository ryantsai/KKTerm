# systemCleaner.fileCategory.programs

- **English value**: `Programs`
- **Namespace**: `systemCleaner`
- **File/component**: `src/modules/system-cleaner/SystemCleanerPage.tsx`
- **UI role**: `label`
- **User flow**: Legend entry and donut slice for executable and library files in the Storage by category card.
- **Tone**: `concise/neutral, dashboard label`
- **Placeholders**: `none`
- **Context/meaning**: A file-type group covering executables, installers, and system libraries (exe, dll, msi, sys and similar). It names files on disk, not installed applications — the Uninstaller section counts those separately.
- **Domain notes**: Distinct from `systemCleaner.apps` (Uninstaller), which lists installed packages rather than executable files.
