- **English value**: `Files downloaded from URL Connections are saved here. Leave blank to use the operating system Downloads folder.`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/UrlSettings.tsx`
- **UI role**: `hint`
- **User flow**: Explains the URL download-folder setting and its empty-value default.
- **Tone**: direct setup guidance
- **Placeholders**: none
- **Context/meaning**: The configured directory overrides the standard Downloads directory; an empty field preserves the OS default.
- **Domain notes**: Preserve URL Connection as KKTerm domain terminology and Downloads as the conventional OS folder.
