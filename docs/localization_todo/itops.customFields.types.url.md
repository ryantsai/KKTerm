# itops.customFields.types.url

- **English value**: `Web URL`
- **Namespace**: `itops`
- **File/component**: `src/modules/settings/ItOpsCustomFieldSettings.tsx`, `src/modules/itops/CustomFields.tsx`
- **UI role**: `label`
- **User flow**: Configure fields in Settings → IT Ops, then edit or follow their values on IPAM records.
- **Tone**: Concise and neutral.
- **Placeholders**: none
- **Context/meaning**: Custom IPAM metadata field configuration and value editing. The operator chooses this data type for a field, not a Connection protocol.
- **Domain notes**: IPAM is global to IT Ops. Connection is a durable openable resource; Rack Device and Network Node are distinct inventory and diagram elements. Saved credentials reference the secret store; no password text is stored in these fields. Use Taiwan terminology for zh-TW, including 自訂欄位、資料、儲存、連線、網路、機櫃.
