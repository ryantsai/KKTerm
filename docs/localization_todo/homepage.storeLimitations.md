# `homepage.storeLimitations`

- **English:** Honest limitations: the Mac App Store build runs inside Apple's App Sandbox — Local terminal is unavailable, remote SSH is unaffected, real folders need a one-time picker grant, and video recording plus the shutdown-timer menu are unavailable. The Microsoft Store build is the full Windows app with a 7-day trial option. Both update through their store.
- **Context/meaning:** Public download-page disclosure of platform-specific Store limitations. The changed meaning is that the Mac App Store build no longer offers Local terminal at all; it is not merely a confined shell.
- **Domain notes:** “Local terminal” is KKTerm's Connection kind. “Remote SSH” remains available because the shell runs on the remote host.
- **Placeholders:** None.
