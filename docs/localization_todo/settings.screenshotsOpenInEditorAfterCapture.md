# settings.screenshotsOpenInEditorAfterCapture

- **English value**: `Open in editor after capture`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/ScreenshotsSettings.tsx`
- **UI role**: `label`
- **User flow**: The user enables this in Screenshots Settings to open newly saved captures in KKTerm's screenshot editor.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: "Editor" is KKTerm's built-in screenshot viewer/editor, not the OS-default image app.
- **Domain notes**: A capture must be saved to the Screenshots library before it can open in the editor.
