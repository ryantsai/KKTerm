# remoteDesktop.fullscreen.toggle

- **English value**: `Toggle full screen`
- **Namespace**: `remoteDesktop`
- **File/component**: `src/modules/settings/ShortcutsSettings.tsx`
- **UI role**: `shortcut action label`
- **User flow**: Labels the configurable RDP/VNC full-screen toggle in Settings → Shortcuts.
- **Tone**: concise/action-oriented
- **Placeholders**: none
