# screenshots.draft

- **English value**: `Draft`
- **Namespace**: `screenshots`
- **File/component**: `src/modules/screenshots/LibraryView.tsx`
- **UI role**: `label`
- **User flow**: The badge appears on a screenshot thumbnail or details row when that image has non-destructive editor changes waiting to be saved.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: “Draft” means saved editable screenshot work that has not been flattened into the original image, not an unfinished message or document.
- **Domain notes**: The original screenshot remains unchanged until the user invokes Save in the screenshot editor.
