# settings.autoBackupFolder

- **English value**: `Backup destination`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/GeneralSettings.tsx`
- **UI role**: `label`
- **User flow**: Labels the optional folder used for automatic and pre-import safety database backups in Settings → General → Settings data.
- **Tone**: `concise/neutral`
- **Placeholders**: `none`
- **Context/meaning**: Destination means the local or mounted filesystem folder where KKTerm writes its managed database-backup ZIP files.
- **Domain notes**: Backup refers to KKTerm database-backup ZIP snapshots, not selective `.kkbackup` exports.
