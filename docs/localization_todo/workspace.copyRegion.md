# workspace.copyRegion

- **English value**: `Capture Region`
- **Namespace**: `workspace`
- **File/component**: `src/modules/workspace/ScreenshotMenu.tsx`
- **UI role**: `button`
- **User flow**: The user opens a workspace Pane screenshot menu and chooses a rectangular capture.
- **Tone**: `concise/neutral`
- **Placeholders**: `none`
- **Context/meaning**: Capture a user-selected rectangular part of the current Pane. Delivery follows Settings → Screenshots rather than always using the clipboard.
- **Domain notes**: Pane is the frontend workspace subdivision; Capture Mode may save to the Screenshots library, copy to the clipboard, or do both.
