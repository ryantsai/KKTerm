# `notes.deepLink.triggerHint`

English: `Type @ to link a connection, workspace, or rack device.`

- **Namespace**: `notes` (Connection notes: the pane-toolbar post-it affordance and the rich-text note editor)
- **UI role**: status
- **User flow**: Hint under the Deep Link picker's search field teaching the faster @ trigger available inside the note.
- **Placeholders**: none. The literal `@` character is the editor's trigger key and must stay `@` in every locale.
- **Domain notes**: "Connection" is the durable stored resource and "Workspace" is the named container of Connections (see `CONTEXT.md`); translate both with the terms already used for those concepts in this locale.

Best-effort translations exist in the locale files; keep this pending file until a
verified localization pass completes per `docs/localization_todo/README.md`.
