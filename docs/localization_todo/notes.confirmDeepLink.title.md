# notes.confirmDeepLink.title

- **English value**: `Open linked item?`
- **Namespace**: `notes`
- **File/component**: `src/modules/notes/NoteEditorSheet.tsx`
- **UI role**: `heading`
- **User flow**: Title of the confirmation sheet shown when a user clicks a Deep Link while the Connection Note has unsaved edits or an image upload in progress.
- **Tone**: concise/neutral question
- **Placeholders**: none
- **Context/meaning**: Confirms opening the selected in-app Deep Link after closing the current note editor. This is distinct from the ordinary `notes.confirmDiscard.title` used when the user closes the editor without navigating.
- **Domain notes**: Deep Link targets can be Connections, Workspaces, or IT Ops rack devices. Do not translate Deep Link as a web URL unless that is the locale's established product terminology.
