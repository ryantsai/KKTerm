# app.openFile

- **English value**: `Open…`
- **Namespace**: `app`
- **File/component**: `src/app/systemFileMenu.ts`, `src/modules/workspace/WorkspaceCanvas.tsx`, `src/app/TitleBar.tsx`
- **UI role**: `button`
- **User flow**: Opens the native file picker from the macOS/Linux File menu or the Windows Workspace plus/title chevron, then launches the selected file ephemerally.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: `Open` means choose and view/edit an existing local file; the ellipsis signals that a picker follows.
- **Domain notes**: Images use the Screenshots editor; other files use an ephemeral Document Tab. No durable Connection is created.
