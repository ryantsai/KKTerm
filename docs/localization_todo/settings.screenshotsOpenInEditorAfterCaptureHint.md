# settings.screenshotsOpenInEditorAfterCaptureHint

- **English value**: `Available when captures are saved to the Screenshots folder.`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/ScreenshotsSettings.tsx`
- **UI role**: `fragment`
- **User flow**: The hint explains why the editor option is disabled for clipboard-only capture mode.
- **Tone**: direct setup guidance
- **Placeholders**: none
- **Context/meaning**: The built-in editor opens library items, so clipboard-only captures cannot use this option.
- **Domain notes**: Screenshots is a Module and the Screenshots folder is its configured library folder.
