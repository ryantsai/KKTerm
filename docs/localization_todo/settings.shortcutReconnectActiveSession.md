# settings.shortcutReconnectActiveSession

- **English value**: `Reconnect active Session`
- **Namespace**: `settings`
- **File/component**: `src/modules/settings/ShortcutsSettings.tsx`
- **UI role**: `label`
- **User flow**: The user sees this action in Settings → Shortcuts and can assign a terminal-focused key combination. It ships without a default binding.
- **Tone**: concise/neutral
- **Placeholders**: none
- **Context/meaning**: Reconnect means intentionally restart the currently focused live terminal Session, not reopen or focus its durable Connection.
- **Domain notes**: Preserve capital-S `Session` as KKTerm's live runtime state. Do not translate it as the durable `Connection` or frontend `Tab`.
