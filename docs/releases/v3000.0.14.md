## Highlights

- **Screenshots & video recording:** Improve screenshot capture timing accuracy, enhance macOS clipboard handling for screenshots, and add support for **video recording cancellation** (with related event handling).  
- **Terminal attention:** Introduce terminal attention notifications and UI indicators in the workspace (for those “did you see that?” terminal moments).
- **Localization clarity:** Add/update localization files across many languages to improve the clarity/accuracy of UI text and documentation.

## New

- **Terminal attention feature** with notifications and UI updates (e.g., attention badge/status) to help you notice when a terminal needs attention. *(Introduced by [v3000.0.14] commit `e674bc0`)*  
- **Video recording cancellation** support, including related event handling. *(Implemented by [v3000.0.14] commit `aa919b8`)*

- **Screenshot capture accuracy:** Enhance screenshot capture delay assertions to improve reliability of screenshot capture tests. *(commit `18ca462`)*

- **Installer & settings support:**
  - Update ARM64 toolchain detection and installer candidate directory logic. *(commit `f56de35`)*
  - Expand `SETTINGS_SEARCH_KEYS` to include additional settings for better user support. *(commit `7ba056c`)*
  - Update About/Settings to include support links and improve localization. *(commit `ef99453`)*
  - Improve “latest support”/installer helper behavior (including terminal attention UI support). *(commit `8130e13`)*
- **Localization cleanup & consistency:** Remove obsolete localization files and update translation descriptions for better terminology consistency in UI text across multiple locales. *(commit `32fc1e4`)*
