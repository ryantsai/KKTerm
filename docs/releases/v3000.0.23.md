# KKTerm v3000.0.23

## Highlights

- Added IT Ops custom fields with validation, editing UI, summaries, links, and navigation.
- Enhanced macOS ACP command handling with App Group integration.

## New

- Custom fields can now be defined and managed for supported IT Ops records, including Connections, network nodes, racks, and rack items.
- Added custom field types including text, multiline, number, boolean, date, URL, credential, select, and link.
- Added support for linking custom fields to related IT Ops records.

## Improved

- Improved custom field validation messages and input handling.
- Number fields now retain incomplete input while editing instead of discarding it—the terminal no longer has to guess what you meant.
- Improved responsiveness, focus handling, and accessibility in custom field settings.
- Updated Chinese and Taiwanese translations for custom-field labels, hints, and validation messages.

## Internal

- Added SQL schema, Rust validation coverage, and UI tests for custom fields, including character counting, number parsing, and blank choice options.
- Added test coverage for macOS App Store file access.

# KKTerm v3000.0.23

## 亮點

- 新增 IT Ops 自訂欄位，包含驗證、編輯介面、摘要、連結與導覽功能。
- 強化 macOS ACP 指令處理與 App Group 整合。

## 新功能

- 現在可以為支援的 IT Ops 記錄定義與管理自訂欄位，包括 Connection、網路節點、機架與機架項目。
- 新增文字、多行文字、數字、布林值、日期、URL、憑證、選擇與連結等自訂欄位類型。
- 新增將自訂欄位連結至相關 IT Ops 記錄的功能。

## 改進

- 改善自訂欄位的驗證訊息與輸入處理。
- 編輯數字欄位時會保留尚未完成的輸入，不再直接丟棄；終端機不用再猜測你的意思。
- 改善自訂欄位設定的響應式配置、焦點處理與無障礙使用體驗。
- 更新自訂欄位標籤、提示與驗證訊息的中文與台灣中文翻譯。

## 內部

- 新增自訂欄位的 SQL 結構、Rust 驗證測試與 UI 測試，涵蓋字元計數、數字解析及空白選項。
- 新增 macOS App Store 檔案存取測試。
- 完整變更記錄：https://github.com/ryantsai/KKTerm/compare/v3000.0.22...v3000.0.23
