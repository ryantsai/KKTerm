## Highlights
- **AI/MCP appearance parity**: AI and MCP tool appearances now align, including **dynamic backgrounds by name**. (PR #785, thanks @ryantsai)
- **RDP Session fullscreen (opt-in)**: New RDP Sessions can start in fullscreen—if you choose it in settings. (PR #787)
- **Stability for shared Dashboard Widget Instance health schema**: Fixes a schema issue that could block release. (PR #788)
- **Windows “Open” quoting**: Correct handling of quoted “Open with…” commands on Windows. (PR #789)
- **Linux release build dependency**: Installs required **PipeWire headers** for the Linux release build. (PR #790) — hopefully your release pipeline doesn’t trip over the usual “missing header” gremlins.
