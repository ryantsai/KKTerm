## Highlights
- **SFTP**: Keep background transfers running even when the SFTP popup is minimized (because your network should not go “into sleep mode”).  
- **SSH**: Accept private-key passphrase input during startup to prevent session timeouts while authenticating.  

## New
- **None** (no user-facing “New” items in this release context).

## Improved
- **SSH Session startup flow**: Startup actions are deferred until authentication completes, preserving pending readiness across **Pane** moves and ensuring saved port forwards and OS detection happen once the live **Session** is ready.

## Fixed
- **SSH private-key passphrase input**: Fixed so the passphrase input is accepted during startup (Issue #768, PR **#769**; reported by **@yanowo**, contributed/fixed by **@yanowo**).  
- **SFTP background transfers minimized**: Fixed so transfers keep running when the SFTP popup is minimized (Issue #766, PR **#770**; reported by **@jpdakwind**, contributed/fixed by **@ryantsai**).  
- **Window state persistence**: Improved persistence/handling for minimized window state (PR **#** not provided in context).

## Internal
- **None** (no purely internal changes listed in the provided release context).

## 亮點
- **SFTP**：即使 SFTP 彈出視窗被最小化，背景傳輸仍會持續進行（因為網路不該跟著「睡著」）。  
- **SSH**：在啟動期間接受私密金鑰（private-key）密碼短語輸入，避免在驗證階段造成 Session timeout。  

## 新增
- **本版本無使用者面向的「新增」項目**（依提供的 release context 判定）。

## 改進
- **SSH Session 啟動流程**：在完成身分驗證後才執行啟動動作；並在 **Pane** 位置切換時保留待完成狀態，確保儲存的 port forward 與 OS 偵測會在即時 **Session** 就緒後執行。

## 修正
- **SSH 私密金鑰密碼短語輸入**：修正使啟動期間的密碼短語能被正確接受（Issue #768，PR **#769**；由 **@yanowo** 提報，且由 **@yanowo** 完成修正/提交）。  
- **SFTP 最小化後仍要繼續傳輸**：修正最小化 SFTP 彈出視窗後傳輸會停止的問題（Issue #766，PR **#770**；由 **@jpdakwind** 提報，且由 **@ryantsai** 完成修正/提交）。  
- **視窗狀態持久化**：改進最小化狀態的持久化與處理（此處 PR 編號在提供的 context 內未給出）。
