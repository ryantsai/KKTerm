# KKTerm v3000.0.24

## Highlights

- Improved embedded RDP full-screen behavior so Connections, Sessions, and Tabs clean up more reliably. The terminal can stay full-screen without playing hide-and-seek.
- Updated Windows recording cancellation to use `Ctrl+Esc` when discarding a recording.

## Improved

- RDP full-screen Sessions now:
  - Properly disconnect and close the Tab when the Connection bar’s close button is used.
  - Confirm remote desktop size changes before applying display updates.
  - Reassert full-screen display settings after entering full screen, including delayed updates.
  - Clean up Session state more reliably when full screen is closed. ([`b248445`](https://github.com/ryantsai/KKTerm/commit/b248445))

## Fixed

- Ensured the `onFullscreenClose` callback is always provided for embedded RDP Connections, preventing incomplete close handling and automatic Tab-close issues. ([`0e8cec4`](https://github.com/ryantsai/KKTerm/commit/0e8cec4))
- Changed Windows recording cancellation to use `Ctrl+Esc` for discarding recordings. ([`09ce30e`](https://github.com/ryantsai/KKTerm/commit/09ce30e))

## Internal

- Updated Rust and project dependencies, including the GitHub Copilot SDK, Tokio, WinRM, Windows bindings, and WebView2 bindings.
- Added default GitHub Copilot model options in tests and updated related CI/release configuration. ([`cda118d`](https://github.com/ryantsai/KKTerm/commit/cda118d))

# KKTerm v3000.0.24（繁體中文・台灣）

## 主要更新

- 改善嵌入式 RDP 全螢幕行為，讓連線、工作階段與分頁能更可靠地完成清理。終端機可以穩定保持全螢幕，不再玩躲貓貓。
- 更新 Windows 錄影取消操作：捨棄錄影時改用 `Ctrl+Esc`。

## 改善

- RDP 全螢幕工作階段現在會：
  - 使用連線列的關閉按鈕時，正確中斷連線並關閉分頁。
  - 在套用顯示更新前，確認遠端桌面尺寸變更。
  - 進入全螢幕後重新套用全螢幕顯示設定，也能處理延遲更新。
  - 關閉全螢幕時更可靠地清理工作階段狀態。([`b248445`](https://github.com/ryantsai/KKTerm/commit/b248445))

## 修正

- 確保嵌入式 RDP 連線一定會提供 `onFullscreenClose` 回呼，避免關閉處理不完整及分頁自動關閉問題。([`0e8cec4`](https://github.com/ryantsai/KKTerm/commit/0e8cec4))
- Windows 錄影取消操作改用 `Ctrl+Esc` 來捨棄錄影。([`09ce30e`](https://github.com/ryantsai/KKTerm/commit/09ce30e))

## 內部更新

- 更新 Rust 與專案相依套件，包括 GitHub Copilot SDK、Tokio、WinRM、Windows bindings 及 WebView2 bindings。
- 為測試中的 GitHub Copilot 模型選項加入預設值，並更新相關 CI／發行設定。([`cda118d`](https://github.com/ryantsai/KKTerm/commit/cda118d))
