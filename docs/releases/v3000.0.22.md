# KKTerm v3000.0.22

## Highlights

- Right-click multiline paste now honors the live confirmation setting in open terminal sessions—less terminal drama.
- Installer support now matches NVM for Windows x64 release assets.
- OpenAI model deprecation handling and release-note generation were updated for the April 2027 retirements.

## Improved

- Removed the redundant fullscreen hint from RDP settings and localization. (`3dd79b6`)

## Fixed

- Applied live multiline paste confirmation changes to open sessions. ([#795](https://github.com/ryantsai/KKTerm/pull/795), `8b83102`, @ryantsai)
- Matched NVM for Windows x64 release assets in the installer. ([#798](https://github.com/ryantsai/KKTerm/pull/798), `4e82660`, @ryantsai)
- Migrated release notes and scoped OpenAI model deprecations for the April 2027 retirements. ([#797](https://github.com/ryantsai/KKTerm/pull/797), `7bb1a22`, @ryantsai)

## Internal

- Preserved the Homebrew tap SSH identity during releases. ([#794](https://github.com/ryantsai/KKTerm/pull/794), `47328e1`, @ryantsai)
- Normalized and validated the Homebrew deploy key. ([#796](https://github.com/ryantsai/KKTerm/pull/796), `f6f97f6`, @ryantsai)

- Installer 現在會比照 NVM，正確對應 Windows x64 發行資產。
- 已針對 OpenAI 於 2027 年 4 月的模型退役更新模型淘汰處理與發行說明產生流程。
