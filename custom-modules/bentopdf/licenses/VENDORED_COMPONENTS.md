# Vendored browser runtime components

The self-contained KKMod build includes these browser/WASM runtime assets:

- `@bentopdf/pymupdf-wasm` 0.11.16 — AGPL-3.0-only
- `@bentopdf/gs-wasm` 0.1.1 — AGPL-3.0-only
- `coherentpdf` 2.5.5 — AGPL-3.0-only
- `tesseract.js` 7.0.0 and `tesseract.js-core` 6.1.2 — Apache-2.0
- Tesseract English trained data `4.0.0_best_int` — Apache-2.0
- Noto Sans Regular at googlefonts/noto-fonts commit
  `ffebf8c1ee449e544955a7e813c54f9b73848eac` — OFL-1.1
- EmbedPDF Japanese, Korean, Simplified Chinese, Traditional Chinese, Arabic,
  Hebrew, and Latin auxiliary viewer font packs 2.8.1 — OFL-1.1

Their upstream package or repository license texts are reproduced in this
package's license and third-party notice files. BentoPDF also bundles PDF.js,
LibreOffice WASM, QPDF WASM, and other browser components documented by the
upstream v2.8.7 source tree and generated dependency inventory.
