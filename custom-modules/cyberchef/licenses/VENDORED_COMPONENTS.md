# Vendored components distributed by CyberChef

CyberChef's source tree includes browser components outside its npm dependency
tree. Their source notices remain in the compiled upstream code where present.

- CyberChef application source and `ascon.mjs` — Apache-2.0, Crown Copyright.
- X86-64 Disassembler JS adaptation by Damian Recoskie and contributors — MIT;
  the copyright and license notice is embedded in the vendored source.
- `remove-exif.mjs` by hMatoba — MIT; the full notice is embedded in the
  vendored source.
- `gost/*` derived from GOST WebCrypto code by Rudolf Nickolaev and attributed
  contributors — Apache-2.0 with the additional BSD-style attribution notices
  retained in the vendored source.
- WHATWG named character reference data — CC BY 4.0, with incorporated source
  portions available under BSD-3-Clause as described by the upstream notice.
- English Tesseract trained data — Apache-2.0, distributed from the
  `tesseract-ocr/tessdata` family of repositories.
